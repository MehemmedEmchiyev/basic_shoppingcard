# Basic Shopping Cart

This project is a simple shopping cart application. Users can add products to the cart, remove them, and view the total amount.

## Technologies

- **JavaScript** - For functionality
- **Tailwind CSS** - For styling

## Installation

To run the project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone <repo-url>
   cd basic-shoppingcart
   ```

2. Run the project using an HTTP server (e.g., VS Code Live Server or Python SimpleHTTPServer).

## Usage

- Add products to the cart.
- View and remove products from the cart.
- Calculate the total amount.

## Deployment

You can deploy the project using a static hosting service like Vercel or Netlify.
